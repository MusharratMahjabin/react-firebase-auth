# React Firebase Authentication

A React web application built with React, React Router, and Firebase Authentication.

## Features

- User Registration
- User Login and Logout
- Firebase Email and Password Authentication
- Protected Routes
- Dashboard for authenticated users
- Profile page displaying user information
- Authentication state persists after page refresh
- Responsive user interface

## Technologies Used

- React
- Vite
- React Router
- Firebase Authentication
- JavaScript
- CSS

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/MusharratMahjabin/react-firebase-auth.git
   ```

2. Navigate to the project folder:

   ```bash
   cd react-firebase-auth
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure your Firebase project in `src/firebase.js` using your Firebase web app configuration. Enable Email/Password authentication in the Firebase Console.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in the terminal.

## Build

To create a production build, run:

```bash
npm run build
```
